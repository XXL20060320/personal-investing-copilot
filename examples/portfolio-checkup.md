# 示例 3：持仓体检与再平衡

> 演示组合视角、数据质检、量化指标与白话翻译。持仓数字由用户上传文件提供，Skill 不内置任何行情。

## 用户说

```
（附 holdings.csv）帮我看看我的组合怎么样，要不要再平衡？
```

## 应该发生什么

1. 读 `references/portfolio-review.md`；上传文件先按 `references/data-and-compliance.md` 解析，再按 `references/data-sources.md` 记来源链（文件名 / sheet / 导出日期 / 单位 / 质量标记）。
2. 分析前数据质检（`references/portfolio-review.md` 第 2.1 节）：单位与币种、是否含现金 / 货币基金、导出日期是否过旧、权重合计、重复行、代码格式；任一异常先修数据或缩小结论范围。
3. `scripts/metrics_calc.py` 算权重、HHI / 有效持仓数、单资产上限、与目标比例偏离、相关性矩阵；标注「依据用户提供的持仓 / 序列计算，时点：〈导出日期〉」。
4. 从组合视角切入：大类分布 → 重复暴露与穿透重合 → 结构性问题点名 → 持仓四层分类 → **带顺序**的调整建议（先退回串用的应急金，再砍跟风仓、合并重复暴露、补核心仓，最后才考虑新标的）。
5. 按 `references/beginner-explainer.md` 把 HHI、相关性、压测金额翻译成「所以呢」；起步阶段用户尤其需要。
6. 再平衡按「定期 + 阈值 + 事件」判断，先算交易成本；费用与规则细节运行时核实，不写具体数值。
7. 定稿前按 `references/release-gates.md` 门控 → 涉及具体调仓动作用免责模板 B。

## 门控检查点

- 命中 BLOCK：把现金 / 货币基金排除在组合外；权重合计 ≠ 100% 仍给集中度结论；用浮亏比例机械建议补仓；一次给 8 条无优先级的调整建议。
- 命中 NEED_REVIEW：导出日期过旧（`quality_flag = stale`）未声明；基金持仓披露滞后却断言「已分散」；用户不熟悉 HHI 等术语却未附白话解释。
- 注意：不逐只做「点评合集」；不因近期涨跌临时改目标比例，除非风险画像或资金期限本身变了。
