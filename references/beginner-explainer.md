# 小白解释层（beginner-explainer）

> 何时读：用户明显不熟悉术语、问「这是什么意思 / 我该看懂什么 / 风险大不大」，或输出里出现了 HHI、估值分位、跟踪误差、折溢价、最大回撤等指标。默认对「现金理财阶段」用户启用。
>
> 本文改编自 Apache-2.0 项目 `china-stock-fund-analysis` 的 `投资小白解释层.md`，按本 Skill 的起步配置主线与自有脚本输出重写；署名见 `THIRD_PARTY_NOTICES.md`。

## 1. 六段式回答结构

不写正式研报时，优先用这六段，顺序不变：

1. **一句话结论**：这个结果说明什么，**不**说该买该卖。
2. **这是什么**：用生活语言解释对象或指标，先白话后术语。
3. **为什么重要**：连到收益、风险、流动性、费用或持有体验。
4. **怎么看**：给可比较的参照（同类区间、目标比例、历史区间），而不是孤立数字。
5. **不能证明什么**：点出最容易被误读的地方。
6. **下一步检查**：列 1–3 件具体可核实的事。

## 2. 语气规则

- 数学不打折，表达不设门槛；必要时用小数字举例，不堆公式。
- 把比率翻译成后果：不说「波动率更高」，说「持有过程中账面浮亏会更大、更久，容易中途拿不住」。
- 不居高临下，不制造紧迫感与错失恐惧，不用「主力」「资金意图」当证据。
- 不确定性直说，不用「长期看好」「风险可控」这类空话遮掩。
- 用户问「能不能买」时，**不推断**其风险承受力、税务、期限与流动性需求，改写成四件事：公开数据支持什么 / 主要风险与情景 / 还缺哪些个人信息 / 需要用户自己或持牌机构核实什么。

## 3. 起步阶段专属翻译

| 用户听到的话 | 应该这样解释 |
|---|---|
| 三层桶 | 把钱按「什么时候要用」分三堆：随时要用的应急金、1–3 年确定要用的、3–5 年以上不动的。只有第三堆才谈权益 ETF |
| 目标权益比例 30% | 是「长期钱里打算承受波动的上限」，不是预测会涨，也不是建议马上买满 |
| 分批 12 个月 | 把一次买入拆成 12 次，降低「刚好买在高点」的影响；**不消除亏损，也不保证更赚** |
| 再平衡 ±5 个百分点 | 涨多了或跌多了导致比例偏离目标超过 5 个点，才考虑调回；这是纪律，不是看多看空 |
| 场内 / 场外 | 场内像在交易所里跟其他持有人买卖，价格实时变动；场外是按日终净值向基金公司申赎。费率、门槛、到账时间都不同，具体规则向券商 / 基金管理人核实 |
| 定投 | 用每月稳定结余按固定节奏投入，重点是「可执行、能坚持」，不是选到最优点位 |

## 4. 术语与指标翻译表

| 术语 | 白话解释 | 最容易被误读成 |
|---|---|---|
| PE / PB 历史分位 | 估值温度计：现在的倍数在过去一段区间里排在什么位置 | 「分位低 = 一定会涨」；样本只有 3 年时尤其不可靠 |
| 跟踪误差 | ETF 实际表现偏离它跟踪的指数的程度 | 「近一年涨得少 = 跟踪差」；基准不同不能横比 |
| 折溢价 | 场内买卖价与基金净值之间的差；溢价买等于多付一笔 | 「溢价高说明大家看好」 |
| 总费率 | 管理费 + 托管费等合计，每年从基金资产里扣 | 只看管理费，忽略托管费与指数授权费 |
| 最大回撤 | 样本区间里从高点到低点最难熬的一段浮亏 | 「历史最大 = 未来最多」，实际可能更大 |
| HHI 集中度 / 有效持仓数 | 组合实际押在少数几只上的程度；有效持仓数越小越集中 | 「买了 10 只就一定分散」；同指数 ETF 重复等于一只 |
| 相关系数 | 两只资产涨跌是否同步；接近 1 说明「看着两只、其实一笔风险」 | 「相关性高 = 更安全」 |
| 单资产上限 / 再平衡阈值 | 事先定好的纪律参数，防止一次押太重或偏离太远 | 「经过回测的最优参数」；它们是**可调整的规划假设** |
| 情景压测 | 假设权益部分下跌 X%，按当前仓位估算账面会浮亏多少钱 | 「预测会跌 X%」；只是线性估算，不含极端情形与费用 |
| 同比 / 环比 | 跟去年同期比 / 跟上一季度比 | 两者混用导致「增长」结论失真 |
| 归母净利润 | 真正属于母公司股东的利润 | 与「净利润」混用 |

## 5. 脚本结果怎么讲给用户

`allocation_calc.py` / `metrics_calc.py` 的每个数字都要配一句「所以呢」：

- **应急金缺口** → 先说「现在还不具备增加权益敞口的条件」，再说缺多少、怎么补；**不要**把 `targets` 里的空值或 `not_applicable` 读成「建议 0%」。
- **HHI 高 / 有效持仓数低** → 「看起来买了好几只，实际上主要靠一两只决定涨跌」。
- **相关性接近 1 的两只标的** → 「这两只合计算一笔风险，分开买没有达到分散效果」。
- **估值分位** → 同时说样本区间与口径；样本过短时明说「只能作参考，不足以判断历史高低」。
- **压测损失金额** → 「按这个假设情景估算的账面影响」，并强调不是预测、不含费用与税费。

## 6. 适当性边界

- 不因用户问了一个代码就推断其风险偏好、收入、家庭负债或投资期限。
- 不把「用户处于现金理财阶段」当成「应当尽快转入场内」的理由；是否具备条件由 `onboarding-and-allocation.md` 的 Step 0 判断。
- 不给目标价、不承诺收益、不制造时间压力。
- 涉及具体动作时，仍按 `data-and-compliance.md` 原文附加固定免责声明。
