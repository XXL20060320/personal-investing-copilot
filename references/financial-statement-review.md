# 上市公司财报体检（financial-statement-review）

> 何时读：用户问「这家公司财报怎么样」「财报有没有雷」「利润是不是真的」，或上传年报 / 季报 PDF、财务数据表时。涉及估值时并行读 `valuation-and-entry.md`。

## 定位

财报体检在本 skill 中是**辅助能力**：以 ETF 配置为主的个人投资者不必逐只深挖成分股财报。适用场景主要是：① 用户直接持有个股；② 用户想买个股而非 ETF；③ 检查某只 ETF 权重股集中暴露的基本面风险；④ 用户单纯想学会读财报。明确告知用户「以 ETF 为主时，这部分只做辅助，不替代组合层面的纪律」。

## 1. 第 0 步：事实与口径确认

先确认：报告期（YYYYQn / YYYYFY）、披露日期、币种、合并报表还是母公司、是否经审计、是否为更正后版本、是否含一次性并表或口径变更。**口径没对齐之前不做同比计算**。

关键区分：净利润 vs 归母净利润 vs 扣非归母；同比 vs 环比；财年 vs 自然年；调整后数据 vs 报表数。跨市场对比先把各家财年拆成实际覆盖的自然年季度，或用 TTM 滚动四季消除财年差异。

## 2. 三表联动检查清单

**利润表**：营收、归母净利、毛利率、净利率、期间费用率、非经常性损益占比；增长是量增还是价增、内生还是并购并表、主业还是一次性。

**资产负债表**：应收账款与存货是否显著快于收入增长、合同负债 / 预收变化、有息负债与资产负债率、商誉占净资产比重、货币资金与短期债务的匹配。

**现金流量表**：经营活动现金流净额、与净利润的比值（现金含量）、资本开支与自由现金流、筹资与分红。利润增长而经营现金流长期跟不上是最常见的质量警报。

三表必须联动：只报「营收 +X%」不构成财报分析。

## 3. 增长质量拆解

按「来源 → 代价 → 持续性 → 失速路径」四步：

1. 增长命题：收入高增 / 利润高增 / 结构性增长 / 低基数恢复，标准不同。
2. 来源：量 vs 价、老产品 vs 新品、内生 vs 并表、单一大客户 vs 普遍需求、景气顺风 vs 份额提升。
3. 代价：利润率是否同步改善、费用投放是否失控、回款是否跟得上、库存 / 应收 / 资本开支是否异常抬升。依赖让利、压货或透支现金的增长要显著降级。
4. 持续性与失速路径：高基数、补贴退坡、需求前置、大客户回落、竞争导致价格回吐、产品周期见顶。要点出**最容易爆的具体环节**，不写泛泛风险。

资本回报：长期 ROE / ROIC 水平、回报来自经营优势还是财务杠杆、是否靠大量一次性扰动。取数要求长周期（近 10 年优先），样本不足时说明局限。

## 4. 异常信号清单（逐项核，命中要解释原因）

- 应收账款 / 存货增速明显快于营收
- 经营现金流与净利润长期背离
- 毛利率与同行趋势相反且无合理解释
- 商誉占净资产偏高、集中计提减值
- 大额非经常性损益撑起利润（资产处置、政府补助、公允价值变动）
- 资本开支连续高于经营现金流、依赖外部融资
- 关联交易、大额其他应收款、对外担保
- 审计意见非标准、财报更正、关键高管或审计机构变更
- 业绩指引措辞变化（「强劲增长」→「稳健增长」）、业绩会问答回避核心问题

命中信号不等于造假，但必须写「需要核实的点」与「下一步该查哪个附注」，不得直接下结论。

## 5. 财报后反应：把「结果」与「表现」分开

结果层（收入 / 利润 / 利润率 / 现金流是否超预期、指引上修或转弱、增长质量）与表现层（盘后 / 次日价格反应、同板块联动、反应幅度是否超出常态）分别写。若股价与 headline 相反，重点解释市场忽略表面利好、真正交易的分歧是什么（增速可持续性 / 利润率触顶 / 某业务拐点 / 指引可信度）。

盘后情绪不等于长期结论；超预期后的漂移可能延续，不把首日反应当全部。价格仍在快速变化时声明「判断仅代表〈时点〉」。

**点评口径补充**（参考 MIT 项目 `himself65/finance-skills` 的 `earnings-recap`，按 A 股场景重写；署名见 `THIRD_PARTY_NOTICES.md`）：

- 「超预期」必须有可核验的一致预期来源与统计口径。A 股多数标的没有可靠的公开一致预期数据，取不到时写「无可核验一致预期，不判断是否超预期」，**不得**用媒体标题里的「超预期」替代。
- 反应窗口以**披露日 / 公告时点**为起点，不是报告期末；盘后披露的反应落在下一交易日。业绩预告、业绩快报与正式定期报告是三个不同事件，不能混成一个「财报」。
- 美股常用的 EPS 实际值 vs 预期值、盘后价格反应等字段不直接套用到 A 股；以营收、归母净利润、扣非归母与经营现金流为主，并注明是否经审计。

## 6. 用脚本算，不手算

`scripts/metrics_calc.py` 接收用户提供的财报数值，计算同比 / 环比、毛利率、净利率、经营现金流 / 净利润、应收占收入、资产负债率、ROE 等。脚本只做确定性计算，不内置任何公司数据；输出标注「依据用户提供的〈报告期〉数值计算」。

禁止凭记忆写出任何财务数字；所有数值来自运行时检索的一手来源或用户上传文件，并标注来源 + 时点。

## 7. 建议骨架

30 秒结论（结果层 / 质量层 / 主要疑点）→ 口径与数据来源 → 三表核心指标表（来源 + 报告期）→ 增长质量拆解 → 异常信号与待核实清单 → 市场反应与核心分歧（若适用）→ 对 ETF 持有者 / 个股持有者分别意味着什么 → 后续跟踪指标与验证周期 → 风险与反向声音 → 免责声明（模板 A）。
