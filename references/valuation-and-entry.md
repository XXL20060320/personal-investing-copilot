# 估值判断与条件化操作（valuation-and-entry）

> 何时读：用户问「贵不贵」「PE 多少算高」「现在能不能买」「该买多少」「要不要加仓 / 减仓」，或 ETF 对比中涉及估值分位时。前提未确认时先跑 `SKILL.md` 的 Step 0 并读 `onboarding-and-allocation.md`。

## 核心三问

1. **该用什么估值方法，为什么**——不生搬硬套。
2. **当前估值反映了市场什么预期**——说清「股价 / 指数里已经定价了什么」，这是高质量估值分析的关键。
3. **重估或杀估值的触发因素是什么**——把结论变成可跟踪的条件。

## 1. 方法选择

| 类型 | 适配框架 | 说明 |
|---|---|---|
| 高成长 | PE / PEG / PS / EV-EBITDA | 高估值不一定贵，看增速与质量是否匹配 |
| 稳健成长 | PE / PEG | 结合长期 ROE 与现金质量 |
| 周期 | PB / 周期中枢盈利 | 用 PE 判断周期股容易反向 |
| 价值 / 红利 | PE / PB / 股息率 | 股息率要验证持续性，不能用单次数值代替 |
| 金融 / 平台 | 分部估值 / P-AUM 等 | 口径与可比公司要一致 |
| 宽基 / 主题 ETF | 指数层面 PE / PB 分位 + 成分盈利趋势 | 先核实指数编制与成分行业权重，再谈分位 |

跨公司比 PE 前先核对财年口径。若用 DCF：WACC 与永续增长率做 Bear / Base / Bull 三情景，不把单一情景当目标价；本 skill **不输出目标价点位**。

## 2. 历史分位的取数纪律

- 主动取长周期（近 10 年优先，至少覆盖一轮完整周期）；3 年样本不足以支撑「历史 70% 分位」这类结论。
- 标注样本区间、数据频率、来源与时点。
- 纵向分位 + 行业 / 同类横向对比一起看；高估值不一定贵、低估值不一定便宜，必须结合质地与阶段解释。
- 取不到长周期数据时，明确写出样本区间与结论的局限，不得用短样本伪装成「历史分位」。

常见表述参考：30% 以下偏低、30%–70% 中性、70% 以上偏高——这是**解读用的经验刻度，不是买卖信号**，输出时标注为参考区间，且不单独作为操作依据。

## 3. ETF 场景的简化处理

起步阶段不要求用户对指数做 DCF。核实三件事即可：① 指数 PE / PB 分位及样本区间；② 成分行业集中度与盈利趋势是否支撑当前分位；③ 与已持有 ETF 的重合度。涉及「股债相对性价比」时必须取数并标注来源与时点，不用记忆里的历史数值。

**重要**：估值分位只回答「贵不贵」，不回答「会不会涨」。对阶段 A/B 用户，默认结论是「按分批 / 定投路径执行，估值分位用于调节节奏而非决定是否入场」。

## 4. 条件化操作框架（替代「逢低布局」）

每条建议写成一行可执行的条件句：

| 条件（可观测、带数据源） | 动作 | 失效条件 | 复盘点 |
|---|---|---|---|
| 例：长期钱已到位 + 应急金覆盖 6 个月 + 当月结余按计划到账 | 按既定金额执行本月定投 | 应急金被挪用 / 收入中断 | 下月同一日 |

规则：
- 条件必须可观测且能追溯数据源，不写「等回调」这类无法验证的条件。
- 动作必须具体到「金额或比例 + 品种方向 + 频率」，但**不给具体买入价位预测**。
- 失效条件必备，避免死扛。
- 市场环境不支持时敢直说「本次不执行」。

## 5. 仓位由风险反推，不由信心正推

1. 先定边界：单笔最大可承受亏损占账户的比例、整体权益仓位天花板（来自资金三层桶）、单一资产占权益仓位上限、行业集中度上限。
2. 不确定性越高，首笔越克制；验证后再放大，不在浮盈基础上盲目加码。
3. 粗略关系：可承受仓位 ≈ 单笔风险预算 ÷ 止损距离。**止损距离过远应缩小仓位，而不是放宽纪律**；没有止损位就没有仓位计算。
4. 组合相关性是隐藏风险：多只高度重合的 ETF 合计算一笔暴露；新增交易按「补充暴露」而非独立头寸处理。
5. 压力测试：按真实波动想一遍开盘跳空、连续不利波动、环境突变；如果心理上无法承受，当前仓位偏大。

对起步用户的默认口径：个股择时与分仓路径仅作补充，**长期钱以定投为主**；任何单只个股或单一主题 ETF 都不应成为组合主要风险来源。

## 6. 加减仓触发与失效条件

- 加仓：原逻辑被强化、走势符合预期、环境支持升级，且资金三层桶未被挪用。
- 减仓：原逻辑被削弱、出现替代标的、资金期限变化（这一条常被忽略）、达到预设止盈纪律、环境恶化。
- 失效条件：逻辑证伪、跟踪的指标下修、组合比例突破上限、产品规则或费率发生实质变化。
- 止损纪律一旦写下不得事后放宽；解套不按浮亏比例机械补仓，先重新审视逻辑。

## 7. 避坑

- 不只报一个 PE 数字就下结论，必须拆解估值背后的预期。
- 不把「低估值」直接等同于「该买」，不把「高估值」直接等同于「该卖」。
- 不写「逢低布局、注意风险」，必须具体条件 + 具体动作。
- 一把梭不是计划；分批与定投是标配。
- 不承诺收益、不给目标价、不预测短期涨跌。
- 涉及具体买卖动作时，回复末尾必须原文附加 `data-and-compliance.md` 的**模板 B**。

## 8. 建议骨架

30 秒结论（贵不贵 + 定价了什么 + 置信度）→ 前提与资金约束 → 估值框架与理由 → 分位数据（样本区间 + 来源 + 时点）→ 已定价预期与重估/杀估值触发因素 → 条件化操作表 → 仓位与压力测试 → 风险与反向声音 → 跟踪提醒 → 免责声明。
