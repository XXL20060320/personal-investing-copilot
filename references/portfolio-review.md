# 持仓体检与再平衡纪律（portfolio-review）

> 何时读：用户给出多只持仓（含 ETF、基金、个股、现金），问「我的组合怎么样」「该砍哪只」「要不要再平衡 / 定投」「亏了怎么办」时。

## 核心原则

**从组合视角切入，不逐只点评。** 让用户先知道自己整体拿的是什么，再点结构性问题，最后给带顺序的调整建议。对起步阶段用户，组合里「现金 / 货币基金」也是持仓的一部分，必须纳入，不能只看场内部分。

## 1. 分析步骤

1. **组合总体画像**：资产大类分布（现金 / 固收 / 权益 / 其他）、权益内部风格与行业分布、持仓数量、集中度、总权益仓位水平，以及各笔资金对应的期限（是否串用三层桶）。
2. **主要风险暴露**：单一行业过重、同类题材高度集中、高相关标的重复（多只同指数宽基 = 一笔暴露）、高波动主题 ETF 占比过高、风格冲突（既想防守又全仓高弹性）、跨境 / 商品的汇率与溢价暴露。
3. **结构性问题点名**：票数过多导致跟踪失效（个人投资者持仓过多基本失控）、核心仓缺失而后排太多、逻辑混乱无统一框架、跟风买入占比高、过度分散拖累效率 / 过度集中放大回撤。允许给明确批评式结论，不要假大空。
4. **持仓分层**：核心仓（宽基 / 稳定器，长期持有）、卫星仓（主题 / 个股，比例受限）、观察仓（逻辑待验证、仓位轻）、问题仓（逻辑弱、占用资金、与期限不匹配）。
5. **总仓位判断**：偏高 / 合理 / 偏低，结合资金三层桶与用户回撤承受力，而不是结合对后市的预测。
6. **调整优先级（明确顺序）**：① 先把串用的应急金 / 短中期钱退回第 0/1 层 → ② 砍掉逻辑最弱的跟风仓 → ③ 合并重复暴露 → ④ 补齐或提高核心仓 → ⑤ 最后才考虑加新标的。
7. **解套场景**：分清「是否值得继续持有」——逻辑还在且价格被错杀才考虑按计划补，逻辑破坏就换掉；**不按浮亏比例机械补仓**。

## 2. 量化检查（用脚本）

`scripts/metrics_calc.py` 对持仓表计算：各标的权重、HHI 集中度、单资产是否超过预设上限、与目标配置的偏离百分点、是否触发再平衡阈值；对用户提供的收益序列计算 Pearson 相关性矩阵。脚本不内置市场数据，输出标注「依据用户提供的持仓 / 序列计算，时点：〈导出日期〉」。

不要空喊「风控」，要给出具体集中度数值和超标的持仓。相关性高时点明「这些标的合计是一笔风险」，并给量化依据。

## 2.1 分析前的数据质检与穿透（不可跳过）

| 检查 | 为什么 |
|---|---|
| 单位（元 / 万元 / 亿元）、币种、是否含现金 / 货币基金 | 漏掉现金会系统性高估权益敞口的合理性 |
| 导出日期、是否为最新快照 | 旧数据只能做回顾，`quality_flag = stale`，不能代表当前状态 |
| 权重合计是否 100%、是否重复行、代码格式是否统一 | 合计不为 100% 时所有集中度数字都不可信 |
| 基金 / ETF 底层成分是否重合 | 「买了 5 只」不等于分散，可能只是同一批股票的五份包装 |
| 持仓披露是否滞后或缺失 | 穿透不完整时写「无法据此断定已经分散」，不下结论 |

命中 `references/release-gates.md` 的红旗时，先修数据、缩小结论范围，再谈调整建议。对起步阶段用户，HHI、有效持仓数、相关系数、压测金额都要按 `references/beginner-explainer.md` 翻译成「所以呢」；例如「有效持仓数 2.1」要说成「看起来买了 6 只，实际涨跌主要由 2 只决定」。

（本节的数据质检与穿透思路参考 MIT 项目 `claude-trading-skills` 的 `data-quality-checker` 与 Apache-2.0 项目 `china-stock-fund-analysis` 的组合诊断，按本 Skill 重写；署名见 `THIRD_PARTY_NOTICES.md`。）

## 3. 再平衡规则

- 触发方式：定期（月 / 季）+ 阈值（偏离目标 ±5 个百分点，属可调整的纪律参数）+ 事件触发（大额资金进出、资金期限变化）。
- 先算交易成本：成本相对调仓金额不划算时不调，可用后续新增资金定向补齐低配资产，减少卖出。
- 再平衡是**恢复目标比例**，不是看多或看空；不因近期涨跌临时改目标比例，除非风险画像或资金期限本身变了。
- 涉及印花税、佣金、最低收费、跨境产品费用时，规则细节运行时核实，不凭记忆写数值。

## 4. 定投计划检查

核对：金额是否来自稳定结余而非应急金、频率是否可执行、是否在下跌时擅自停投、是否因短期涨幅临时加码、是否有自动扣款与复盘记录。起步阶段「坚持执行纪律」的价值高于「选到更好的标的」，但不得表述为收益保证。

## 5. 建议骨架

30 秒结论（组合画像 + 最突出的 1–2 个结构问题）→ 前提与资金分层 → 持仓与权重表（来源 + 时点）→ 集中度 / 相关性 / 重复暴露 → 结构性点名 → 持仓四层分类 → 条件化调整顺序与失效条件 → 再平衡 / 定投检查清单 → 风险与反向声音 → 跟踪提醒 → 免责声明（模板 A；含具体买卖动作用模板 B）。

## 6. 避坑

- 不从逐只标的切入做「点评合集」。
- 不把现金 / 货币基金排除在组合外，否则会高估权益风险暴露的合理性。
- 不用「分散投资」笼统带过，必须指出具体重复暴露。
- 不因浮亏比例给补仓建议。
- 调整建议必须排优先级，避免同时给 8 条让用户无从执行。
