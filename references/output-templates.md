# 对话研报模板（output-templates）

> 何时读：准备输出结论前。模板是骨架不是填空题，按实际拿到的数据裁剪；拿不到的部分用「数据缺口声明」明确缩小范围，不要留空或编数。

## 通用要求

- 中文表头、结论先行、数据与结论一致。
- 每个数据块标注来源 + 时点 + 口径；同一来源可在表头统一标注。
- 涉及配置比例、仓位、买卖动作时，回复末尾原文附加 `data-and-compliance.md` 的固定免责声明模板，且模板之后不再追加任何内容。
- 默认对话内输出，不生成文件，除非用户明确要求。
- 列举标的逐个带标准代码（A 股 6 位 / 港股 5 位 / 美股 ticker）。

## 输出契约（每次实质分析都应齐备）

骨架可以裁剪，但下列七项信息不能丢；缺数据就明确写缺口，不要留空、不要编数。

| 契约项 | 落在骨架的哪里 | 最低要求 |
|---|---|---|
| Scope 范围 | 结论 / 前提 | 标的、期间、基准、数据截止时点、用户阶段 |
| Sources 来源 | 数据表标注 + 末尾运行记录 | 可点击 URL 或文件名、访问日期、来源层级 |
| Method 方法 | 分析段 | 公式、样本区间、口径、成本与费率假设、数据滞后 |
| Run log 运行记录 | 末尾「数据来源与运行记录」 | 脚本与参数、失败与降级、待核实事项 |
| Findings 发现 | 结论 + 数据表 | 简明事实链与可量化驱动 |
| Risks 风险 | 风险与反向声音 | 数据质量、流动性、集中度、口径、模型局限 |
| Next checks 下一步 | 跟踪提醒 | 具体要核实什么、何时复核 |

- 引用港美股或混合市场行情快照时，逐条标注**币种 + 市场 + 行情时点**，并说明时区口径未经端点确认；`data_cutoff` 只是字符串排序结果，不得写成「统一数据截止时点」。汇率、境外交易规则与税费须提示用户向券商核实，A 股红涨绿跌约定不适用。

输出契约改编自 Apache-2.0 项目 `china-stock-fund-analysis` 的 Output Contract，按本 Skill 的对话研报形态重写；署名见 `THIRD_PARTY_NOTICES.md`。

## 输出前门控与解释层

- 定稿前按 `references/release-gates.md` 判定 **PASS / NEED_REVIEW / BLOCK**。BLOCK 时只交付不含操作结论的分析部分，并说明缺什么；NEED_REVIEW 时把软性问题逐条写进「数据缺口 / 风险」并下调置信度。
- 用户处于现金理财阶段、不熟悉术语，或输出中出现 HHI、估值分位、跟踪误差、折溢价、最大回撤等指标 → 按 `references/beginner-explainer.md` 补白话解释（六段式可压缩为结论后的一小段，但「不能证明什么」和「下一步检查」不能省）。
- 固定免责声明仍是回复最后一块内容，其后不再追加运行记录、署名或任何文字；运行记录放在免责声明**之前**。

## 数据缺口声明模板

```
## 数据缺口
当前数据源未覆盖〈具体指标 / 具体标的〉；最近可用时点为〈YYYY-MM-DD / YYYYQn〉，
来源〈…〉。因此本报告不出具〈受影响的结论〉，仅保留〈可以成立的部分〉。
需补齐〈具体数据〉后再更新结论。
```

不得用「大约」「估计」「据经验」填补缺口，也不得先给一个数字再加「待核实」。
